# Aktau Marina Bay — сайт отеля (макет, версия 3)

Статический сайт без сборки: HTML, CSS, JavaScript. Оформление и содержимое разделены:
оформление правит разработчик, содержимое — отель через админку.

## Структура

| Где | Что |
|---|---|
| `index.html` | Каркас страницы: блоки, заголовки, пустые места под данные |
| `css/styles.css`, `css/mockup.css` | Оформление и анимации |
| `js/main.js` | Базовое поведение: меню, форма бронирования |
| `js/mockup.js` | Вкладыши номеров, карточки, ленты, календарь, окна, смахивание |
| `js/hotel-date.js` | Общая дата отеля в часовом поясе Актау |
| `js/content.js` | **Движок содержимого**: читает `content/*.json` и собирает карточки по шаблонам |
| `content/*.json` | **Содержимое**: спецпредложения, номера, карточки разделов, отзывы, вопросы, документы, настройки |
| `doc.html`, `js/doc.js` | Страница документа (оферта, правила и т. п.): `doc.html?d=<код>` |
| `admin/` | Админка (Sveltia CMS): `index.html`, настройки `config.yml`, инструкция для отеля `guide.html` |
| `images/cards/` | Уменьшенные копии фото для карточек (800 px) |
| `images/uploads/` | Фото и файлы, загруженные через админку |

## Как это работает

1. Сотрудник отеля меняет запись в админке (`/admin/`) — админка сохраняет JSON-файл в репозиторий GitHub.
2. GitHub Pages публикует изменение за 1–2 минуты.
3. На странице `js/content.js` загружает `content/*.json`. Каждый раздел отображается после получения своего файла.
   Интерактивные элементы раздела подключаются после его появления на странице (`window.contentSections`).

Правила текста из админки: всё выводится как текст (HTML не выполняется), `[[…]]` подсвечивается как «не заполнено»,
записи с `published: false` и спецпредложения вне `active_from` / `active_to` не выводятся.

## Админка

- Вход: «Войти с помощью токена доступа» — fine-grained токен GitHub с доступом к репозиторию, право **Contents: Read and write**.
- Для удобного входа сотрудников без токена можно развернуть [Sveltia CMS Authenticator](https://github.com/sveltia/sveltia-cms-auth) (Cloudflare Workers) и указать `base_url` в `admin/config.yml`.
- Пути в `admin/config.yml` указаны от корня репозитория `bildnplus-ai/aktau-marina-bay-maket`, версия лежит в папке `v3/`.

## Переезд на домен отеля

1. `admin/config.yml`: `repo`, `site_url`, `display_url`, убрать префикс `v3/` из путей, `public_folder: /images/uploads`.
2. `index.html`: адреса в `og:*` и в JSON-LD (`schema.org`), убрать `noindex` и плашку «Демо-макет».
3. Контакты, реквизиты, документы — заполнить в админке.

## Проверка локально

```bash
python -m http.server 8000
```

Сайт: http://localhost:8000/ · админка: http://localhost:8000/admin/ («Работать с локальным репозиторием» в Chrome/Edge).
