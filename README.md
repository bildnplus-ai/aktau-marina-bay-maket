# Aktau Marina Bay — демо-макет

Макет будущей версии сайта отеля Aktau Marina Bay (Актау) для согласования с командой отеля.
**Это не рабочий сайт**: бронирование, цены и реквизиты — заглушки.

- Пунктирные плашки «…» — места под данные от отеля (цены, реквизиты, время, контакты).
- Метка «Временное фото» — 3D-визуализации до живых фотографий номеров.
- Кнопки «Выбрать» / «Забронировать» показывают подсказку; в рабочей версии они откроют модуль бронирования Exely.
- Страница закрыта от поисковиков (`robots.txt`, `noindex`).
